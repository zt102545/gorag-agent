# 模块接入清单

新增后台模块时，至少完成以下检查，避免出现“前后端只做了一半”的状态。

## 后端

- 是否定义了 `application` 层入口，避免 `handler` 直接调用具体存储实现。
- 是否明确了领域对象或输入/输出 DTO。
- 是否完成路由注册。
- 是否声明了鉴权与角色要求。
- 是否接入了最小日志或错误返回语义。
- 如果有异步处理，是否有入队、状态和失败重试策略。

## 前端

- 是否新增了对应 `feature` 目录或复用已有 feature。
- 是否补齐 API 封装与类型定义。
- 是否挂载了路由和菜单入口。
- 是否处理了权限态和空态。
- 是否有最小可验证页面流。

## 验证

- 至少完成一次后端编译检查。
- 至少完成一次前端构建或类型检查。
- 如果模块涉及前后端联动，确认菜单、接口、权限三者一致。

## 当前已补齐的典型闭环

- `API Key` 模块已补充后端路由注册。
- 管理台已补充 `API Keys` 菜单和路由入口。
